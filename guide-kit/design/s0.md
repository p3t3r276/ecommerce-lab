# Design S0 · Nền móng sớm (foundation)

## 1. Scope

S0 builds the five things that are hard to bolt on later: AppHost + ServiceDefaults (OpenTelemetry, health, resilience), Postgres with one database per service, Keycloak + Gateway.Web (YARP, JWT), an Nx workspace with `storefront`/`admin`, `libs/auth` and a hand-written `libs/api-client`, and a Testcontainers test harness. No business feature exists yet; the only endpoint is Catalog `GET /ping`.

**Gate (verbatim, v3 › S0):** Đăng nhập storefront qua Keycloak được; `GET /api/ping` qua gateway có token được 200, không token được 401.

| Week | Sessions | Goal (Detail) |
|---|---|---|
| w01 | 1–4 | Machine has all tools; solution skeleton builds; `aspire run` opens the dashboard; Postgres + pgAdmin run with 8 databases. |
| w02 | 5–8 | Keycloak runs in the AppHost with realm `shoplab` auto-imported; an access token can be obtained for sample users; shared auth layer in BuildingBlocks. |
| w03 | 9–12 | Request goes Gateway.Web → Catalog.Api with authentication; a two-hop trace is visible in the dashboard. |
| w04 | 13–16 | Nx workspace with `storefront` and `admin`; login via Keycloak; `admin` blocks users without role `admin`. |
| w05 | 17–20 | OpenAPI + Scalar for Catalog; hand-written `api-client` calls `/api/ping`; Testcontainers suite; S0 gate passes. |

Out of scope (later steps, room left only): EF Core / DbContext / migrations (S1), `IEndpoint` + `ApiExtensions` (S1 session 25), `AppErrors`/ProblemDetails (S1 session 26), `TestKit` + `ShopLabApiFactory` + `TestAuthHandler` (S1/S2), `CurrentUser` (S2), `/internal` blocking at the gateway (first internal route, S2), `store_id` attribute (S7), `IntegrationEvent` base (S3).

## 4. Questions for the user

### Q-s0-01 · Where the SPA reads the user's roles
Context: `libs/auth` needs the realm roles for `roleGuard('admin')` (Detail session 15–16). Keycloak puts `realm_access.roles` in the **access token** by default, not in the ID token. OAuth treats the access token as opaque to the client: it is meant for the API (here the gateway), and its format may change. The choice changes the realm file (shared) and `AuthService.roles`.
- [ ] A. Decode the access token in the browser and read `realm_access.roles` — no realm change, one helper; but the SPA depends on the API token's format, which is the habit OAuth guidance warns against.
- [x] B. Add a per-client mapper (`oidc-usermodel-realm-role-mapper`, claim `realm_access.roles`, ID token only) to `storefront`, `admin`, `pos`, and read roles from the ID token claims — correct separation (ID token is for the client, access token for the API), one more mapper per client to click in session 7.
- [ ] C. Ask the backend: a `GET /api/me`-style endpoint returns roles — single source of truth, but needs an endpoint that does not exist until S2 and an extra call before every guard.
Recommendation: B because it is the textbook split between ID token and access token, costs only one mapper, and keeps the guard synchronous.
Reason (user): theo đề xuất (option B ticked in file).

### Q-s0-02 · Where the SPA keeps tokens
Context: `storefront` and `admin` are public clients with code flow + PKCE talking to Gateway.Web with bearer tokens (v3 stack row 10, Detail session 15). `angular-oauth2-oidc` stores tokens in `sessionStorage` by default; the storage decides what survives a reload and what an XSS bug can steal. (A cookie-based BFF would change the architecture and is out of scope.)
- [x] A. `sessionStorage` (library default) — survives reload, isolated per tab, cleared when the tab closes; readable by any script on the page (XSS).
- [ ] B. `localStorage` — shared between tabs and survives browser restart; longest exposure to XSS and to a shared machine.
- [ ] C. In memory only (custom `OAuthStorage`) — nothing persisted, smallest XSS window; every reload goes back to Keycloak (silent because of the SSO cookie, but a visible redirect and slower dev loop).
Recommendation: A because it is the library default, keeps the dev loop fast, and the lab has no third-party scripts; the guide shows how to switch to C as an experiment.
